复合触发器——为什么存储器行业需要这个机制
核心问题：单维度高分无法触发明确买入信号

存储器行业最好的买入机会发生在：周期谷底 × 通算估值极低 × 共识未恶化。

这三件事同时出现的频率极低（约每3-5年一次），但每次都对应5年内最好的回报窗口。

问题在于：三件事分散在不同维度里，每件单独得高分不会自动触发"买入"动作。 SNDK在$38.50时：dim6=5/5（谷底✅），估值极低✅，共识中性✅——三条全满足。 但在原框架里，这三个高分被稀释进最终得分，并没有告诉投资者"现在是三重确认的买入机会"。

复合触发器把三重条件合并为一个独立的额外奖励（+15分），让框架能在最关键的时机明确输出"⭐已触发"的信号。

触发器三个条件的设计依据
条件阈值设计逻辑历史依据
A. 周期位置
dim6 ≥ 4/5		谷底或复苏早期确保在供给过剩→正常化之前进场，而不是在峰值追涨DRAM历史底部（2019、2023）均出现在产能利用率<75%时
B. 通算估值极低
EV/归一化EBITDA ≤ 7.2x		历史中位数×1.2（6x×1.2）不只是"比历史便宜"，而是明显低于合理中枢，留有安全边际内存行业通算EV/EBITDA历史中位约6x；7.2x是合理上限
C. 共识未恶化
共识偏差 ≥ -5%		共识不低于股价5%以上避免在"已知问题"（共识已大幅低于股价）时盲目买入；确保市场认知未完全崩溃如铠侠当前共识-20.7%，说明专业分析师已看到严重问题

为什么当时质量分只有39.6，但仍应该买？

这是框架中最重要的一个悖论：质量差的周期底部公司 可以是 比质量好的周期高峰公司 更好的买入机会。

在$38.50时，SNDK的质量分只有39.6——公司当时确实没有特别出色的商业质量：

  • • 刚分拆，独立历史为零
  • • NAND谷底，当期亏损或微利
  • • $2B债务，财务压力大
  • • HBF还没有发布

但估值分高达98（触发后），因为：

  • • EV/归一化EBITDA 1.7x——用谷底价格买到了中周期合理价值的28%
  • • NAND周期反转几乎是确定的（内存行业历史上从未出现永久过剩）
  • • 分拆折价+强制卖出产生了人工低估

框架的正确处理方式是：高估值分（98）× 低置信度调整 → 合理的最终分（B/60）。 不是把它打成A（因为质量确实不高），而是打成B（因为价格已经充分反映了风险）。 B(60) + 触发器激活 = 明确建仓信号，即使不是核心持仓。
