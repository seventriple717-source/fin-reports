六、全驱动力地图

主要驱动力 直接触发估值重定价

① 国际OTA业务高速增长（结构性，最安全的增长引擎） 结构性驱动
FY2025国际OTA总预订额+60% YoY，已占总营收40%。亚太、中东、欧洲三地预订均>100% YoY。关键点：国际业务完全不在SAMR管辖范围内，是中国监管风险完全解耦的增长资产。中国出境游2026年预计>225M次（超2019年历史高点），Trip.com持有>50%市场份额。

② 入境旅游爆发式增长（新蓝海，政策支持+极低基数） 结构性蓝海
2025年入境游预订翻番，服务约2,000万入境旅客。中国入境旅游GDP贡献仅0.5%（vs 泰国10%），管理层明确指出'至少5-10倍增长空间'。2026年入境游再增70-80%，已入驻63,000+新酒店。这是100%不受SAMR影响的纯增量市场。

③ 净现金$14.7B（占市值44%）提供极厚安全垫 价值支撑
RMB 1,058亿净现金，EV/EBITDA仅6.7x（全球OTA最低估值）。即使SAMR罚款$10亿（Alibaba先例4%年收入，对应约$3.6亿），仅消耗净现金的7%，不影响任何业务运营。持续回购为股价底部提供技术支撑，设置了有效的估值下限。

七、隐藏因素专项分析

【最被低估】美国证券集体诉讼 = 强制卖盘机器

Hagens Berman 于2026年5月正式提起证券欺诈集体诉讼，覆盖2024年4月30日至2026年1月13日间持股的投资者。核心指控：管理层在AI调价工具监管风险已高度明确的情况下，仍对外宣传该工具为'长期战略基石'，构成实质性误导披露。类期截止日为2026年5月11日（现已过）。直接后果：①类期内机构有主动卖出动机（锁定损失参与赔偿）；②持有'clean hands'政策的机构基金被迫清仓；③任何积极披露均被折价——'管理层之前骗过我们一次'。这是独立于SAMR之外的第二条法律轨道，目前市场严重低估其对股价的机械性压力。

AI调价工具关闭 = 核心竞争力永久损失（非临时合规举措）

该工具的真实功能：自动扫描竞争对手价格 → 强制酒店在Trip.com保持最低价 → 不配合酒店被降低搜索曝光度（隐性惩罚机制）。这与Booking Holdings在欧洲被罚的MFN（最惠国条款）性质完全相同。管理层声称这只是合规关闭，但实质是：酒店重获定价自主权后，Trip.com维持佣金溢价的核心机制失效，佣金竞争能力永久下降。JD.com 3年零佣金进入酒店预订市场恰好在此时发起，进一步加速行业佣金率向下压缩趋势。

联合创始人同日辞职：比罚款更危险的个人法律风险信号

范敏（Trip.com总裁、联合创始人）+ 季琦（联合创始人）于2026年2月26日同日辞去董事会，官方无任何解释。历史参照：在中国互联网监管案例中，创始人在调查期间撤退往往意味着其预判将面临个人连带法律责任（而非仅企业罚款）。最了解公司内幕的人同步选择撤退，是比任何分析师预测更有效的负面信号。同月JPMorgan+Barclays将目标价从$90下调至$75，认可护城河已实质受损。

双重法律轨道叠加：SAMR（中国）+ SEC诉讼（美国）无时间表

SAMR中国反垄断调查 + 美国证券欺诈集体诉讼同时进行，两套法律体系完全独立。SAMR：无明确调查时间表，历史上大型平台调查周期1-2年（参考美团、Alibaba）；SEC诉讼：类期已定，但庭审/和解可能持续2-4年。在两条轨道同时存在期间，股价将持续承受结构性卖压，与基本面完全脱钩——这正是'好业绩但股价不涨'的根本原因。

11、护城河与风险评估

长期护城河（未被破坏）

  • AI调价工具永久关闭：佣金溢价核心机制失效，取费率面临长期压缩压力
  • JD.com 3年零佣金入场：战略性烧钱，行业佣金率结构性下移

  • VIE结构+中美关系：中美关系恶化可能触发ADR摘牌尾部风险
  • SAMR+美国证券诉讼双重法律开销：法务成本+管理层精力消耗
