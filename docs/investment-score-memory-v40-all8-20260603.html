v4.0 改动说明：为什么这样调整
问题：SanDisk 1年涨10x，但评分只有C(51)

这暴露了原框架的三个系统性盲点：

盲点1：期权价值权重只有6%
SNDK的HBF是"要么平台要么商品"的二元结构——若成功，TAM从$20B NAND跳升到$100B+平台。原框架把这种凸性回报结构折进6%权重的DCF里，严重低估。
→ v4.0：dim7可选性权重6%→12%，新增二元期权模型分支

盲点2：没有问"市场在哪里错了"
原框架只问"贵不贵"，不问"谁的认知是错的"。HBF尚未进入主流分析师模型，意味着当分析师开始建模HBF，目标价将大幅上调——这是识别超额回报的核心信号，但原框架完全没有捕捉。
→ v4.0：估值dim2新增共识偏差标准（分析师均价 vs 当前股价）

盲点3：债务按静态余额处理
SNDK的$2B债务在原框架里是固定扣分项。但FCF年化$4B，覆盖率200%——实际上半年就可以还清。把一个6个月内即将消失的风险当作持续性风险处理，导致评分过于悲观。
→ v4.0：估值dim3改为FCF债务覆盖率（>200%则升为3/5，债务不视为实质风险）
