Section 02
数据中心推理芯片：六大技术路线
每条路线的本质逻辑、代表产品与核心差异化
01
HBM GPU
通用高带宽 GPU
本质：通用并行计算芯片，搭载 HBM（高带宽内存）。HBM 相当于把内存叠在芯片旁边，带宽是普通 DDR 的 10-20 倍。

为什么叫 GPU：最初用于游戏渲染（并行处理像素），因为矩阵乘法和渲染的数学结构相同，被复用于 AI 训练和推理。

训练和推理都能做，是当前数据中心绝对主力。
Nvidia H100/B200 AMD MI300X/MI450 市占率 ~78%
02
Hyperscaler ASIC
超大规模定制芯片
本质：专门为特定工作负载设计的固化芯片（Application-Specific Integrated Circuit）。Google 的 TPU 只为跑 TensorFlow/JAX 优化，AWS Inferentia 只为推理优化。

为什么比 GPU 便宜：不需要通用性，去掉了 GPU 里 70% 的「用不上的」电路，同等算力功耗降低 4-5 倍，成本下降 3-5 倍。

限制：模型架构变化后芯片可能就浪费了，且只有超大规模公司才值得自研。
Google TPU v7 AWS Inferentia 3 Meta MTIA v2
03
SRAM / LPU 架构加速器
片上内存 + 确定性调度 · 超低延迟
本质：用片上 SRAM 替代外部 HBM，把计算和数据放在一起，消除数据来回搬运的延迟。SRAM 访问约 1-5ns，HBM 约 100ns——快 20-100 倍。

两条子路线：
▸ WSE（Cerebras）：整张晶圆 = 一块芯片，最大化 SRAM 体积（44GB），靠物理容量赢延迟
▸ LPU（Groq/Nvidia）：编译器把每个时钟周期全部预排好，"确定性调度"消除 GPU 的动态等待开销，500MB/芯片 × 256 颗 = 128GB 片上 SRAM/机架

Nvidia 花 $200 亿买入 Groq IP，将 LPU 用于 Vera Rubin 架构的 Decode 阶段——这是最强的市场背书。
Cerebras WSE-3 Nvidia Groq 3 LPU ≤120B 高速推理
04
LPDDR 推理 GPU
低功耗 · 气冷企业专用
本质：GPU 架构，但把 HBM 换成 LPDDR5X（笔记本电脑用的内存）。LPDDR 带宽只有 HBM 的 1/3，但功耗低 70%，容量可以做到 160GB，价格便宜得多。

这是三路分类里没有的第四条路：Intel CRI 是目前唯一代表。目标客户是那些机房用不了液冷（H100 700W 必须液冷）的企业。

150-300W = 气冷数据中心可以直接插入运行，无需改造机房。
Intel Crescent Island 2027 量产 唯一气冷推理卡
05
RDU · 数据流处理器
可重构 · Prefill/Decode 分离
本质：Reconfigurable Dataflow Unit（可重构数据流处理器）。介于 GPU 通用和 ASIC 专用之间——通过算子融合大幅减少内存访问次数，可以用软件重新配置适配新模型。

关键洞察：AI 推理的两个阶段有完全不同的计算特征——Prefill 需要高算力（处理输入），Decode 需要低延迟（逐 token 生成）。RDU 专为 Decode 阶段优化，与 HBM GPU 搭档使用，形成异构推理系统。

Intel 与 SambaNova 深度合作/收购，是 Intel 推理战略的重要拼图。
SambaNova SN50 Intel 合作方 Decode 专用
06
中国独立生态
昇腾 · 寒武纪 · 地缘隔离
本质：受出口管制驱动形成的独立技术路线，而非主动的差异化创新。昇腾（华为）是 GPU 架构（CANN 软件栈），寒武纪是 NPU 架构（BANG 软件栈），两者均使用 HBM 类内存。

为什么单独一类：这些产品无法出口、西方产品无法进入中国，形成了平行市场。技术路线本质上是在追赶 Nvidia GPU，但被出口管制冻结在 2-3 代之前。

昇腾主导中国市场，寒武纪是补充选项。
昇腾 910C/920 寒武纪 MLU590 中国市场专属
③-A · LPU 深度解析 — Groq / Nvidia Groq 3
核心创新：确定性调度
GPU 每个 token 生成时需动态决定调度，引入不可预测等待。LPU 编译器提前把每个时钟周期的每个操作全部排好，运行时零决策开销，延迟完全可预测。每颗 Groq 3 芯片含 500MB 片上 SRAM，带宽 80 TB/s；256 芯片组成 LPX 机架，共 128GB 片上 SRAM，可装入完整 70B FP8 模型。

③-B · SRAM-WSE 深度解析 — Cerebras WSE-3
核心思路：把整张晶圆变成一块芯片
普通芯片一张晶圆切成几百个 die，每个 die ~858mm²。Cerebras WSE-3 不切割，整张 46,225mm² = 一块芯片，集成 4 万亿晶体管、90 万 AI 核心、44GB 片上 SRAM。

片上带宽 ~20 PB/s，比 H100 HBM3 的 3.35 TB/s 高约 6,000 倍。权重直接存在 SRAM 里，每次生成 token 不需要从外部内存读取，延迟从 ~100ns 降到 ~1-5ns。

④ · LPDDR GPU 深度解析 — Intel Crescent Island（CRI）
核心思路：低功耗内存换气冷可行性
HBM 每 GB 价格是 LPDDR 的 5-8 倍，功耗高 3-5 倍。CRI 选用 LPDDR5X：带宽 ~1.5 TB/s（H100 的 45%），但容量 160GB，整卡 TDP 仅 150-300W。

160GB 可完整装入 70B FP8 模型（需 70GB）后还有 90GB 给 KV Cache，而 H100 的 80GB 在长上下文会触发显存换页。

全球 70-80% 企业数据中心按气冷设计（机架上限 10-15kW），H100 单机箱（8卡）就超过这个数字，改造液冷一个机架需 $5-20 万。CRI 可直接插入现有气冷机架，无需改造。

⑤ · RDU 深度解析 — SambaNova 可重构数据流处理器
核心思路：算子融合 + 三层内存体系
GPU 跑 LLM 时，矩阵运算之间有大量中间结果写回 HBM 再读出，40-60% 时间在搬数据而非计算。RDU 通过算子融合把多个连续运算合并成一个数据流，中间结果留在片上，减少内存访问 10-50 倍。

三层内存：① 片上 SRAM（超快）→ ② DDR（较快，容量大）→ ③ NVMe SSD（慢，容量极大）。编译器自动决定数据放哪层，可透明地服务超出 SRAM 容量的大模型。
差异化：Decode 专用 + 可重构
与 GPU 搭档：Prefill / Decode 分离
HBM GPU 处理 Prefill → RDU 处理 Decode
Intel + SambaNova CRI + RDU 是 Intel 推理完整方案
✅ 优势："可重构"让模型架构变化（Transformer→MoE→SSM）可用软件适配，生命周期远长于 ASIC
⚠️ 挑战：SambaNova 建立 9 年仍未规模化；Nvidia 把 LPU 整合进 Vera Rubin 压缩了独立市场空间；生态鸡与蛋持续

为什么 LPDDR GPU 和 RDU 参与者这么少？
LPDDR GPU：逆主流，只有 Intel 有动机
行业共识是"带宽越高越好"，LPDDR 主动降带宽换低功耗，方向相反。Intel 做这件事是因为无法在 HBM GPU 正面竞争，需要差异化出口。AMD 和 Nvidia 已占据超大规模云市场，不需要转移资源做气冷方案。

气冷企业市场真实，但被视为"利基"——体量不够让巨头改变战略。
RDU：洞察太早，Nvidia 把市场空间占走了
SambaNova 2017 年建立，9 年没达成规模化——是市场信号。Prefill/Decode 分离架构洞察直到 2024-2025 才被主流认可，市场教育成本极高。

Nvidia 把 Groq LPU 整合进 Vera Rubin 本质上是"自研 RDU 逻辑"——验证了路线，同时把市场空间压缩掉了。
哪种技术路线最优？ 商业最优 ≠ 技术最优。HBM GPU 统治市场靠的是 CUDA 生态飞轮（更多用户→更好优化→更多用户）+ Nvidia 年均 $180 亿研发投入，不是任何单一技术维度最优。LPDDR GPU 和 RDU 的共同困境都是"鸡和蛋"：用户少→软件优化少→性能落后→用户更少。2030 年技术终局最优解可能是 PIM（存算一体），但商业主导权在 Nvidia 那里，除非中国生态或 MoE 架构变革打破飞轮。
第七条路线（新兴）：PIM 存算一体——Samsung HBM-PIM、SK Hynix AiMX，把计算单元直接嵌入内存芯片，消除数据搬运开销。2028-2030 年进入主流，可能同时颠覆 HBM GPU 和 SRAM 架构。
Section 03
高价值推理场景 × 技术路线匹配
按业务价值场景分类，区分「技术最优」与「实际首选」，气冷是部署约束而非使用场景
三个关键澄清：
① 「实时」= 文本响应延迟 <500ms，不是语音通话——用户在对话框发消息，等到屏幕上出现第一个字的时间。语音 AI 是另一套硬件栈（ASR+TTS）。
② 气冷是部署约束，不是使用场景——它影响哪些硬件能部署，但场景本身（代码、金融、法律）与气冷无关。
③ 超大规模云厂商跑自己 Agent = ASIC + HBM GPU；企业客户自建 Agent = 只有 HBM GPU 实际可选（ASIC 买不到）。

为什么 Agent 爆发对 SRAM 的利好是「乘法效应」而非「线性效应」：
SRAM 在 ≤70B 小模型上推理速度是 HBM GPU 的 12 倍。Agent 工作流里存在大量「轻量编排调用」（工具选择、步骤验证、快速路由，用 7-13B 小模型就够），这类调用在 Agent 链里出现 20-50 次。
GPU：每次 2 秒 × 50 次 = 100 秒；SRAM：每次 0.2 秒 × 50 次 = 10 秒。延迟差距在链式调用中被放大 10×。
但注意：Agent 的主力大模型调用（70B+ 复杂推理）超出 SRAM 容量，仍是 HBM GPU 的天下。SRAM 受益的是「编排层」，不是「推理主体」。
气冷是什么 · 为什么 Intel CRI 选它 · 是否战略失误
气冷（Air Cooling）= 用风扇吹散热片，这是 2000-2020 年数据中心的标配，不是高科技。全球约 70-80% 企业数据中心按气冷设计，机架功耗上限约 10-15kW。H100 单机箱（8卡）= 5.6kW，超出上限；B200 单卡 1000W，更无法部署。
Intel CRI（150-300W）可以直接插入现有气冷机架，企业机房零改造成本。这不是技术退步，是市场细分——针对有推理需求但没有液冷改造预算的企业棕地（Brownfield）。
是否战略失误？三个风险：
① 高通 AI200 用了 768GB LPDDR + 液冷，说明 LPDDR 的自然演进是"更大容量+液冷"，Intel 的气冷路线是更激进的取舍，缩小了目标客户群
② H100 PCIe 版本约 300W，已兼容很多气冷机架，直接覆盖 Intel CRI 的核心目标客户
③ 企业 DC 改造速度：AI 用电成本压力正在驱动企业加快液冷改造，到 2027 年时气冷棕地市场可能已经大幅缩小
vs 中国芯片比较无意义：Intel CRI 受出口管制无法进入中国市场。昇腾 910C（500W）和寒武纪（350W）均需液冷，中国企业气冷机房同样面临问题，但这个市场 Intel 没有机会参与。

Section 06
终局形态：异构协作，而非单一胜者
2030 年推理基础设施不是某一种芯片赢者通吃，而是分工明确的异构生态
训练市场 vs 推理市场的根本差异：训练是「跑得快」的问题——越快越好，Nvidia GPU 赢者通吃合理。推理是「用得值」的问题——不同场景对延迟、吞吐、成本、功耗的要求截然不同，不存在一种芯片全场景最优，因此不会出现单一架构垄断。

HBM GPU 的终局角色
市场份额从 80% 降至 55%，但绝对规模持续扩大。大模型（400B+）、企业 Agent 大上下文工作流、训练——没有替代品。CUDA 护城河 + Groq LPU 整合，覆盖全场景。Nvidia 是终局最稳的赢家。
SRAM/LPU 的终局角色
约 5% 高价值利基。Agent 的轻量调用（快速决策、工具执行确认）是真实需求。Nvidia 整合 Groq LPU 是最强背书，但也意味着 Cerebras 独立性风险。MoE 架构普及是最大救星——激活参数 ≤37B，SRAM 容量够了。
商业 ASIC（高通/Broadcom）的终局角色
这是被忽视的增长路线。高通 AI200/AI250 代表了"外售推理 ASIC"的商业模式——不只给自己用，卖给中国 CSP 和全球企业。前提是 AI 架构稳定（Transformer/MoE 持续 5+ 年），ASIC 投资回报才合算。
Intel CRI 的终局：高风险赌注
气冷企业市场真实，但三个条件同时满足才能成功：① 18A 良率如期达标 ② 软件生态完成 ③ 气冷企业棕地在 2027 年前未被 H100 PCIe / ARM 方案占领。高通 AI200 用了更大容量但液冷，说明同赛道的"正确"演进方向可能不是气冷。
中国生态：确定性最高的增量
结构性确定：出口管制 + 中国 AI 投资增长 = 国内需求锁死。昇腾 920（加入 FP8）+ CloudMatrix 进化 + 华为自有 Fab 突破，是三个可观测的里程碑。高通 AI200 进入中国市场是新变量，但体量上不威胁昇腾主导地位。
PIM：2030 年后最重要的颠覆者
条件：Samsung/SK Hynix HBM4-PIM 量产且成本溢价 <40%。若成真，同时解决带宽和能效两个瓶颈，HBM GPU 和 SRAM 两条路线都会被重写。是唯一真正能改变格局的"第七类"，但 2026-2028 年前不会成为市场变量。

最重要的假设依赖：所有预测都依赖"MoE 架构是否成为主流生产标准"这个单一假设。若 DeepSeek 式低激活参数 MoE 成为行业标准 → SRAM/LPU 的容量瓶颈被解除，市场空间大幅扩大；若未来主流模型走向"更大密集模型"（Dense 参数增大）→ SRAM 边缘化，HBM GPU 和 ASIC 主导。MoE 的胜负是推理芯片格局最重要的一阶不确定性。
PIM 存算一体论文：中间方案都是过渡产品？
用户的核心判断基本正确
AI 推理芯片所有架构创新的本质，都是在解决同一个问题：数据从内存搬到计算单元的距离太远，耗时太长。

各路线解决方案的激进程度：
· HBM GPU：把内存叠在 GPU 旁边（CoWoS 封装）
· SRAM/LPU：把数据直接放在芯片上
· RDU：用算子融合减少搬运次数
· PIM：直接在内存里做计算，彻底消除搬运

PIM 是这个问题的「根本解」，其他路线都是程度不同的「部分解」。
但 PIM 不会消灭所有中间方案
PIM 是 HBM 的升级，不是 GPU 的替代。
PIM 把计算嵌入 HBM 内存，但 GPU 核心（Tensor Core 矩阵运算）仍然需要。未来高端 GPU = Tensor Core GPU + PIM HBM，是叠加而非替换。
不会被 PIM 消灭的：HBM GPU（升级为 GPU+PIM）、超大规模 ASIC（改用 PIM 内存更高效）
可能被 PIM 压缩的：SRAM/LPU（PIM HBM 带宽大幅提升后，SRAM 的带宽优势缩小）
不受 PIM 影响的：Intel CRI 气冷场景（物理机房散热约束 PIM 解决不了）
研究与投资视角：按时间维度分层
2026-2027 近期
HBM GPU 代际 + SRAM 验证
B200→B300→Rubin 性能曲线；Groq 3 LPU 落地；Cerebras OpenAI 交付节奏
2027-2029 中期
商业 ASIC + 昇腾 920 + Intel 18A
高通/Broadcom AI 芯片商业化；昇腾 920 FP8 量产；Intel 18A 良率验证
2029-2032 长期
PIM 存算一体（最重要）
HBM4/HBM5 内嵌计算；Samsung/SK Hynix 量产良率；Nvidia GPU + PIM 集成
Intel CRI 和高通 AI200 是 2-3 年的过渡性机会窗口，不是 5-10 年的长期结构性趋势。RDU 作为独立公司已被 Nvidia 战略性覆盖。长期结构性押注：Nvidia GPU 平台的 PIM 集成演进 + 中国昇腾的国内市场增长——前者是全球逻辑，后者是地缘逻辑，两者均有较高确定性。
终局结论：异构协作 + PIM 升级，而非单一胜者
2030 年推理基础设施将是分工协作的异构系统：Prefill 用 HBM GPU（逐渐集成 PIM），Decode 用 SRAM/LPU（Nvidia 内化），大批量用 ASIC，Agent 编排层受益于 SRAM 低延迟优势，中国市场独立运行（昇腾主导）。

中间方案（Intel CRI、RDU、独立 Cerebras）本质上是"内存带宽墙"问题的不同临时解法，PIM 是根本解法但要等到 2028-2030 年。研究 PIM 的长期价值最高，但 2026-2027 年的近期市场变量仍然是 Nvidia Rubin/LPU 生态 + 昇腾 920 量产。
