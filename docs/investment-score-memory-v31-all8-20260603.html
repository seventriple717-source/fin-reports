前瞻判断框架说明
📌 为什么需要前瞻判断？ 纯粹的历史执行评分会惩罚"正在反转的公司"，错过最佳买入时机。三星的HBM3E失败是2024-2025年的历史事件，而HBM4E首发是2026年5月的新信号——两件事的权重在投资决策中应该完全不同。v3.1引入的前瞻信号框架将"叙事反转触发器"和"待验证条件"显式化，让打分系统更适合实际投资决策。
