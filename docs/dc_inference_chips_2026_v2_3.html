Section 02
七大技术路线深度解析
每条路线的架构本质、代表产品、核心优劣势与商业状态
① SIMT HBM GPU — 中神通，现在的老大
架构本质（SIMT = 单指令多线程）：数千个小核心同时执行同一指令，通过 Tensor Core 专用单元加速矩阵运算。HBM 通过 CoWoS 封装堆叠在芯片旁边，带宽是普通 DDR 的 10-20 倍。

统治市场的原因不是技术最优，而是 CUDA 飞轮：更多用户→更多优化库→更多开发者→更多用户，几百万开发者 + 几十亿行 CUDA 代码构成最强护城河。

✅ 优势：软件生态最成熟、全场景适配（训练+推理）、大模型容量支持最好、规模化能力最强

⚠️ 劣势：价格极高（H100 $25-35K、B200 $45-55K）、功耗高（700-1,000W必须液冷）、小 batch 延迟偏高

市场地位：约 78% 市占率，是所有其他路线的对标基准。Nvidia Vera Rubin 架构同时整合了 Groq LPU，形成双轨布局。

Microsoft Maia 200 的特殊性：Azure 内部专用，HBM3e + 272MB 片上 SRAM，3nm 工艺，宣称比 TPU v7 FP8 更高，比现有 Azure 系统性价比提升 30%。内部推理 GPT-5.2 和 Copilot 工作负载。
② 脉动阵列 ASIC — 南帝，大厂造芯的佼佼者
为什么脉动阵列（Systolic Array）不同于 GPU：
GPU（SIMT）：每个时钟周期动态决定哪个核心做什么，适合不规则计算。
脉动阵列：数据像心跳一样在 PE 网格里同步流动，每个 PE 只做乘加，专门为密集矩阵乘法设计，Transformer 的 Attention 层正好是这种模式。

Google TPU v7 (Ironwood) 关键参数：
• 192GB HBM3，7.37 TB/s
• Sparse Core 专用单元，MoE 稀疏计算
• 最多 4,096 芯片组网（3D Torus 拓扑）
• ~4,600 TFLOPS FP8
✅ 优势：矩阵运算效率极高、MoE 模型专项优化（Sparse Core）、性能完全可预测、大规模扩展能力强

⚠️ 劣势：仅 Google 内部使用，不对外销售；灵活性差，非矩阵任务效率低；编程模型复杂（JAX/XLA）

Meta MTIA 路线演进：
早期（MTIA v2/200）用 SRAM+LPDDR，没有 HBM；新一代（MTIA 400/450/500）已转向 HBM，Meta 官方说"HBM 带宽是影响 GenAI 推理最重要因素"。这个转变说明：当工作负载从推荐系统转向 LLM，即使自研厂商也被迫选择 HBM。
③ SRAM / LPU / WSE — 东邪西毒北丐，各有绝学
③-A Cerebras WSE-3（西毒·晶圆级）
整张晶圆不切割，直接做成一块芯片。90 万 AI 核心、44GB 片上 SRAM、带宽 220+ TB/s。

关键纠正（来自 IEEE 论文实测）：Cerebras 在批量吞吐上也是最强（5,280 t/s），不只是低延迟场景。代价是 23kW 系统功耗，能效最差（0.09 tokens/J vs Blackwell 7.8）。

容量墙：44GB SRAM 装得下 70B 模型，装不下 DeepSeek V3（671B）或 Claude Sonnet（~1T）。公开上线最大模型仅 ~120B。
③-B Groq LPU / Nvidia Groq 3（东邪·确定性流水线）
编译器提前把每个时钟周期的每个操作全部排好，运行时零调度开销，延迟完全可预测。230MB 片上 SRAM，80 TB/s 带宽。

实测延迟最低：TTFT 220ms（Blackwell 450ms），延迟一致性最好（CoV=0.02），能效 0.86 tokens/J（第二，仅次于 Blackwell 的 7.8 的差距说明其高功耗问题）。

Nvidia 以 $200 亿整合 Groq IP，将在 Vera Rubin 架构中用 Groq 3 LPU 专门负责 Decode 阶段。
③-C Graphcore IPU（北丐·多核SRAM）
1,472 个独立 tile，每个 tile 自带 608KB 内存，900MB 片上 SRAM，45 TB/s 内部带宽。定位细粒度并行和不规则 workload，小批次延迟极低。

现状：SoftBank 2024 年收购 Graphcore，产品商业化推进缓慢，主要在学术/研究机构使用。批量吞吐（IPU-POD64）约 780 t/s，能效 0.65 tokens/J，在六款对比芯片中居中。

架构意义 > 商业意义：Graphcore IPU 证明了"海量小 tile + 分布式片上 SRAM"路线的可行性，是 Cerebras WSE 的不同实现思路（WSE 是一整张晶圆；IPU 是很多小 tile 互联）。

④ LPDDR 气冷 GPU — Intel Crescent Island（CRI）的独特路线
LPDDR5X 是什么：Low Power DDR，笔记本电脑使用的内存。带宽约 1.5 TB/s（H100 的 45%），但价格是 HBM 的 1/5-1/8，功耗低 70%，容量可做到 160GB。

气冷是什么：用风扇吹散热片散热，H100（700W）必须液冷，CRI（150-300W）可以直接放进气冷机架。全球约 70-80% 企业数据中心按气冷设计（机架上限 10-15kW），这是真实的部署障碍。

确认：CRI 只有 LPDDR5X，无 HBM，无显著片上 SRAM。这是多个来源一致证实的规格，是目前数据中心推理芯片中唯一走 LPDDR 单一内存路线的产品。
✅ 核心差异化：唯一可以在气冷企业机房直接插入使用的高端推理卡；160GB 可完整装入 70B FP8 模型后仍有 90GB 给 KV Cache；企业部署零改造成本。

⚠️ 主要风险：
• H100 PCIe 版本约 300W，已兼容部分气冷机架，直接压缩 CRI 目标市场
• 高通 AI200 选了 LPDDR + 液冷（768GB），说明行业对 LPDDR 路线的自然演进方向不是气冷
• 推理速度估算仅 14-20 t/s（70B 模型），远低于 HBM 竞品
• 量产依赖 Intel 18A 良率，执行风险高

时间线：H2 2026 客户样品，2027 量产
⑤ 商业推理 ASIC — 高通 AI200/AI250（外售，不局限自用）
与超大规模内部 ASIC 的本质区别：Google TPU 只给 Google 自己用；高通 AI200 是对外销售的推理 ASIC，面向中国 CSP（出口管制红线外）和全球企业。

AI200 规格：768GB LPDDR + Hexagon NPU + 液冷，rack 级推理方案。
AI250：AI200 + 近内存计算架构（near-memory compute），进一步提升有效带宽，定位更高端工作负载。

战略逻辑：手机业务增速放缓 → 高通急需找到芯片业务新增量 → 云 AI 推理 ASIC 是最近的大市场。
有趣的对比：高通 AI200 vs Intel CRI，同用 LPDDR，但方向相反：

高通 AI200：768GB LPDDR + 液冷 → 大容量、高性能、普通机房
Intel CRI：160GB LPDDR5X + 气冷 → 小容量、低功耗、棕地机房
这说明 LPDDR 内存方案的自然演进方向（高通认为）是"更大容量 + 液冷"，而不是"更低功耗 + 气冷"。两家用了相同内存类型但走向了完全不同的产品定位。

Broadcom 的角色：协助设计 Google TPU 和 Meta MTIA，是最强的"背后推手"型 ASIC 设计公司，预计 2027 年 AI ASIC 收入超 $1,000 亿。
⑥ 中国独立生态 — 昇腾主导，地缘隔离驱动
昇腾（华为）核心数据：
• 910C：800 TFLOPS BF16，1,800 GB/s HBM2e，500-600W，无 FP8（仅 INT8/BF16，效率损失约 30%）
• CloudMatrix 384（384 片协同）：1,943 t/s 吞吐，系统级弥补单卡劣势
• 制程：SMIC 7nm DUV，低于 TSMC 7nm，良率和性能均受限
• 920 路线图：加入 FP8，但依赖设备突破

寒武纪 MLU590：算力约 H100 的 40-50%，政府/国企多元化采购需求驱动，商业互联网大厂基本不用。
为什么单独一类：出口管制形成平行市场，这些芯片无法出口，西方芯片无法进入中国，形成独立闭环。

高通 AI200 的中国角色：高通芯片不踩出口管制红线，面向中国 CSP（字节跳动、阿里、腾讯）的 H100 缺口提供替代选项。但体量上不威胁昇腾在中国的主导地位。

⑦ PIM 存算一体 — 根本解，等待 2028-2030（来源：EET-China 文章第6节 + 本报告延伸）
本质：把计算单元嵌入 HBM 内存芯片内部，数据不需要搬出来，直接在内存里完成矩阵运算。AI 推理所有架构创新都在试图解决"数据离计算太远"这一问题，PIM 是根本解。

代表产品：Samsung HBM-PIM（AquaBolt-XL）、SK Hynix AiMX。目前处于早期部署/验证阶段，未大规模商用。

与其他路线的关系：PIM 是 HBM 的升级，不是 GPU 的替代。未来高端 GPU = Tensor Core GPU + PIM HBM 叠加，而非取代。
EET-China 文章的相关趋势预测（第6节）：

• 异构内存系统：HBM（热数据）+ CXL-attached DRAM（温数据）+ NVMe（冷数据），支持比 HBM-only 大 5-10 倍的模型，推理性能仅下降 15-30%
• 专用 KV Cache 引擎：长上下文（32K-1M token）下 KV Cache 是主要内存挑战，专用硬件可在同样内存预算下支持 8-10 倍的上下文长度
• CXL 内存池化：计算利用率提升 15-41%，内存利用率提升 28-49%，TCO 降低 22%

时间线：PIM 进入主流预计 2028-2030 年，在此之前 HBM GPU 和 SRAM 路线共存。

🏆 赢家排行（各维度）
综合最优：Nvidia Blackwell B200
能效第一（7.8 tokens/J），吞吐第二（4,560 t/s），延迟第二（450ms）。三个维度没有短板，是花同样的电费能做最多事情的芯片。适合所有场景，软件生态最成熟。买它不会错。
延迟最稳：Groq LPU
首 token 时间 220ms（最快），延迟波动 CoV=0.02（最稳定，Blackwell 是 0.12 的 6 倍差距）。如果你的业务需要每次请求都能「一样快」（金融风控、实时客服 SLA 保障），Groq 是首选。但吞吐量有限（450 t/s）。
吞吐最强但最费电：Cerebras WSE-3
吞吐第一（5,280 t/s），同时延迟低。听起来完美，但 23kW 功耗意味着同样的任务量，电费是 Blackwell 的 86 倍。买吞吐买到了，电费账单会很惊人。仅在极端高并发且不计电费的场景才值得。

最让人失望：Intel Gaudi 3
吞吐排第四（1,840 t/s，是 Blackwell 的 40%），延迟最不稳定（CoV=0.23，最差），能效倒数第二（0.78 tokens/J）。这一数据解释了为什么 Gaudi 3 在 2024 年没有完成 $5 亿销售目标：性能全面落后，没有任何维度能打。Intel 自己已经实质性放弃这条路线。
商业边缘化：Graphcore IPU
能效中规中矩（0.65 tokens/J），延迟最不一致（CoV=0.32），吞吐量有限（780 t/s）。没有一个维度领先，现已被 SoftBank 收购，主要在学术圈使用，商业价值边缘化。
最重要的隐藏结论：软件决定 40% 性能
同一块 Blackwell，不同推理框架（vLLM vs TensorRT-LLM）、不同批处理策略、不同量化方式，性能差距高达 40%。买好芯片只是第一步，软件工程能力决定你能用出多少性能。
能效=经济性：推理是按请求量计费的变动成本。能效差 18.5 倍意味着：同样服务 100 万次请求，Cerebras 的电费是 Blackwell 的 86 倍。规模越大，这个差距对利润的冲击越大。这是为什么 Nvidia 能保持高毛利而 Cerebras 持续亏损的根本原因之一。

高价值业务场景 × 技术路线匹配
关键前提：超大规模云厂商（Google/AWS/Microsoft/Meta）和普通企业的"实际首选"完全不同——前者有 ASIC 可用，后者只能买 GPU
为什么"技术最优"≠"实际首选"，而且两者要区分部署主体：
超大规模云厂商（Google、AWS、Meta）：训练和推理大量工作负载跑在自研 ASIC（TPU/Inferentia/MTIA）上，成本是 GPU 的 1/4-1/5；代码助手、企业 Agent 这些场景在它们那里都有 ASIC 在承担主力。

IPU（Graphcore）在场景里的定位补充

Section 08
终局推演：技术路线命运 vs 公司命运
先澄清一个关键逻辑：技术路线的胜负 ≠ 推动这条路线的公司命运。SRAM 路线在壮大，Cerebras 独立公司高风险，这两件事完全不矛盾。
先拆解"SRAM放大 vs Cerebras淘汰"的表面矛盾
❌ 错误理解：SRAM 路线在放大，但做 SRAM 的 Cerebras 会被淘汰——这不是自相矛盾么？

✅ 正确理解：技术路线的赢家是 Nvidia，不是 Cerebras。

Nvidia 已经以 $200 亿买走了 Groq（SRAM/LPU 最关键的 IP），把 SRAM 架构整合进 Vera Rubin。SRAM 这条路线因此在壮大——壮大的受益者是 Nvidia，而不是 Cerebras。

同样的逻辑适用于 RDU：Prefill/Decode 分离的思想（RDU 的核心）已被 Nvidia 自己实现，但 SambaNova 这家公司的独立前景依然黯淡。
规律：技术先驱者往往不是商业赢家。

技术路线被验证 → 大厂以收购的方式"吸收"这个技术 → 技术继续活着，先驱公司以被收购的形式"消失"。这在科技史上是标准剧本：

• Groq 发明了 LPU → Nvidia 花 $200 亿买走 → LPU 技术活在 Vera Rubin 里
• Cerebras 发明了 WSE → 最可能结局是被 Nvidia/微软/Google 收购 → WSE 技术被整合进更大平台
• SambaNova 发明了 RDU → 思想被 Nvidia 自己实现了 → SambaNova 缺少独立存在的空间

所以终局分析必须分两轨：「什么技术赢」和「谁的股票/公司值得投资」。

IEEE 2025 论文指向的近期架构趋势 → 对推理市场的商业影响（非技术语言版）
① 三层内存体系（HBM+CXL+NVMe）取代单一 HBM
现在买一台 AI 服务器，HBM 是唯一的大内存选项，但贵且有限。未来会像"手机内存+云存储"的分层模式：热数据放 HBM（快，贵），温数据放 CXL 扩展内存（中速，便宜），冷数据放 NVMe（慢，极便宜）。效果：同样的钱可以服务比现在大 5-10 倍的模型，推理成本大幅下降。受益方：云厂商和 CXL 内存供应商（三星、SK Hynix）。
② 长上下文成本问题被 KV Cache 引擎解决
现在处理 1M token 的长文档（整个代码库、法律案卷）成本极高，因为需要保存大量"历史记忆"（KV Cache）占满显存。专用 KV Cache 引擎通过压缩和分层存储，在同等内存下支持 8-10 倍更长的上下文。这直接降低企业 Agent 和长文档分析的服务成本，可能是 2026-2027 年推理经济性最大的改善点。
③ MoE 芯片化 → 催生新型 ASIC
模型架构向 MoE（只激活部分专家）迁移，意味着芯片需要专门的"路由逻辑"来分配计算。Google TPU v7 已有 Sparse Core，未来会出现专门的 Expert Router ASIC。这是 ASIC 赛道的新细分品类，Broadcom 最可能是受益者。对 Cerebras 和 Groq 来说，MoE 让 SRAM 容量瓶颈得到缓解（激活参数小），是重要利好。
④ 计算和内存分开买 → 数据中心建设方式变革
传统买"GPU 服务器"=计算和内存捆绑在一起。未来会出现"计算资源池 + 内存资源池"分开建设，按需动态分配。效果：计算利用率提升 15-41%，TCO 下降 22%。这会让数据中心的建设逻辑从"买硬件"变成"买资源池"，对 Nvidia 来说是机会（卖计算资源）也是挑战（失去对内存配置的控制）。
与我们终局推演的一致性检验： IEEE 论文的四个趋势全部指向同一个方向——推理成本的持续下降。三层内存、KV Cache 引擎、解耦架构都是在用系统工程降低单 token 的服务成本，而非靠单纯的芯片算力提升。这与我们"HBM GPU 主导、ASIC 壮大、SRAM 利基、PIM 未来根本解"的判断高度一致。唯一需要修正的是：我们低估了 KV Cache 引擎和三层内存在近期（2026-2028）的商业影响力，这两个变量对推理经济性的改善可能早于 PIM 的成熟。

终局结论：技术路线是异构协作，公司命运是强者通吃
技术维度：没有单一架构赢者通吃。HBM GPU 保持主导（~55% 份额），但 ASIC、SRAM/LPU、商业 ASIC、中国生态各自占据稳定的细分。推理市场的终局是分工协作——Prefill 用 HBM GPU，Decode 用 LPU/SRAM，长上下文靠 KV Cache 引擎，大批量靠 ASIC，大容量靠 CXL 三层内存，气冷企业靠 Intel CRI（若如期），中国靠昇腾，远期靠 PIM。

公司维度：赢家高度集中。Nvidia 是最大赢家（GPU + 吸收了 SRAM 技术 + CUDA 生态）；Broadcom 是 ASIC 设计的幕后受益者；昇腾是中国的结构性机会。Cerebras、SambaNova 等先驱公司大概率以"被收购"方式退出独立舞台，技术被保留但公司消失——这是科技史的标准剧本，不是失败，而是另一种成功。

IEEE 论文的核心洞见与我们高度一致，但补充了一个重要视角：近期（2026-2028 年）改善推理经济性的关键不是等 PIM 成熟，而是三层内存、KV Cache 引擎、MoE 硬件化这三个系统工程解法，它们比 PIM 来得更早、更确定、影响更直接。
